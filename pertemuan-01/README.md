1. Konsep Dasar Pemrograman Web
Dari materi ini saya mulai memahami bahwa pemrograman web adalah proses untuk membuat sebuah website yang bisa diakses melalui browser. Sebelumnya saya hanya tahu website dari sisi pengguna, tetapi setelah belajar materi ini saya mulai mengerti bahwa di balik sebuah website ada proses pemrograman yang membuat website tersebut bisa berjalan.
2. Arsitektur Klien-Peladen
Arsitektur klien-peladen atau client-server merupakan cara client dan server saling berkomunikasi. Contohnya ketika saya membuka sebuah website, browser yang saya gunakan bertindak sebagai client yang meminta data kepada server. Kemudian server memproses permintaan tersebut dan mengirimkan hasilnya kembali ke browser.
3. HTTP Request dan Response
HTTP Request dan Response adalah proses pertukaran data antara client dan server. Request merupakan permintaan yang dikirim dari client, sedangkan response merupakan balasan dari server. Dari materi ini saya jadi lebih memahami bagaimana ketika kita membuka atau mengakses suatu website, sebenarnya ada proses komunikasi antara browser dengan server.
4. HTML, CSS, JavaScript, PHP, dan MySQL
Saya memahami bahwa masing-masing teknologi mempunyai fungsi yang berbeda. HTML digunakan untuk membuat struktur halaman website, CSS untuk mengatur tampilan, dan JavaScript untuk membuat website lebih interaktif. PHP digunakan untuk memproses data di server, sedangkan MySQL digunakan untuk menyimpan dan mengelola data. Saya masih belajar menggunakan teknologi-teknologi tersebut karena masih di tahap dasar.
5. Hubungan Antarteknologi
Setelah mempelajari materi ini, saya memahami bahwa HTML, CSS, JavaScript, PHP, dan MySQL sebenarnya saling berhubungan dalam pembuatan sebuah website. HTML menjadi dasar struktur halaman, CSS mengatur tampilannya, JavaScript menambahkan interaksi, sedangkan PHP dan MySQL dapat digunakan untuk mengolah serta menyimpan data. Jadi, setiap teknologi memiliki perannya masing-masing agar sebuah website dapat berjalan dengan baik.
