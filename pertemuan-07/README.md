## Deskripsi

Project ini merupakan tugas Pertemuan 07 mata kuliah Pemrograman Web Dasar yang membahas pemrograman PHP pada sisi peladen (server-side).

## Materi Pembelajaran

1. Penggunaan metode POST pada PHP.
2. Penggunaan metode GET pada PHP.
3. Pengolahan data dari form HTML.
4. Validasi input pengguna.
5. Penggunaan variabel dan konstanta.
6. Operator PHP.
7. Percabangan if, elseif, else, dan switch.
8. Perulangan for dan while.
